# AdventureWorks Sales Performance Dashboard

An interactive Power BI report for exploring sales performance across revenue, profit, orders, products, customers, and regions.

## Dashboard preview

![AdventureWorks sales dashboard overview](assets/dashboard-preview.png)

## Report highlights

- **$24.9M revenue**, **$10.5M profit**, **25.2K orders**, and a **2.2% return rate** in the overview shown in the report.
- Revenue trends over time and orders by product category.
- Product-level order, revenue, and return-rate comparisons.
- Monthly revenue, orders, and returns indicators.
- Additional customer and geographic views, with report filters for exploring different segments.

The figures above are the values displayed in the overview screenshot; selections in the report can change them.

## Files

- `Adventure Works.pbix` — Power BI report with its data model and report pages.
- `assets/dashboard-preview.png` — overview screenshot.
